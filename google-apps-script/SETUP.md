# 바이브코딩 사전예약 → Google Sheets 연결 (최초 1회)

홈페이지 사전예약 폼은 이미 적용되어 있습니다. 다만 이 저장 주소를 연결하기 전에는 폼이 '접수 연결 준비 중'으로 표시되고 **제출이 차단**됩니다.

## 1. 구글시트 만들기
1. 접수 내역을 받을 구글 계정으로 https://sheets.new 접속
2. 문서 이름을 `바이브코딩 전자책 사전예약 접수`로 변경
3. 스프레드시트 메뉴 **확장 프로그램 → Apps Script** 선택

## 2. 사전예약 저장 코드 설치
1. 현재 저장소의 `google-apps-script/Code.gs` 전체를 복사
2. Apps Script 편집기의 `Code.gs`에 붙여 넣고 저장
3. **배포 → 새 배포 → 유형: 웹 앱**
4. **다음 사용자로 실행: 나 / 액세스 권한이 있는 사용자: 모든 사용자**
5. 액세스 권한을 승인하고 배포된 **웹 앱 주소(/exec)** 를 복사

## 3. 홈페이지와 연결
1. 주소를 `assets/preorder-config.js` 파일의 `window.VIBE_PREORDER_WEBAPP_URL` 값에 입력
2. 저장/커밋 후 GitHub Pages 자동 배포
3. 홈페이지 `#preorder-form`에서 테스트 접수
4. 새 창에서 접수 성공 및 접수번호 확인
5. 구글시트에 생성된 `사전예약접수` 탭의 실제 행 확인

## 구글시트 저장 열

접수일시 | 접수번호 | 카페닉네임 | 연락처 | 이메일 | 문의사항 | 결제수단 | 접수상태 | 유입페이지

- 결제수단: 카드 / 현금
- 실제 카드 승인·계좌 입금 결과를 검증하는 기능은 포함되지 않습니다.
- 이름/이메일/전화번호 등이 포함되므로 구글시트는 공개하지 마세요.
- 스크립트는 테스트 완료 후 승인 데이터만 운영용으로 관리하세요.
- 필요한 경우 사용자에게 삭제 요청 접수 및 개인정보 보관 기한을 고지해야 합니다.

현재 ChatGPT Google Drive 연결은 스프레드시트 생성 요청에서 `403 PERMISSION_DENIED`가 발생해 Google Sheet나 Apps Script 웹 앱을 대신 생성·배포할 수 없었습니다. 구글시트에서 위 과정으로 생성 후, **웹 앱 /exec 주소를 채팅에 보내면 사이트 연결 값은 바로 반영**할 수 있습니다.
